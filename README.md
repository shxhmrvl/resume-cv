# Online CV — Mohamad Raziq Shah

Personal CV website built with Jekyll and based on the Orbit theme.

## GitHub Pages

This repository is configured for GitHub Pages at:

`https://shxhmrvl.github.io/resume-cv/`

In **Settings → Pages**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`.

## Edit resume details

Update `_data/data.yml`. The public address is intentionally limited to `Simpang, Perak`; do not add a full home address to this public repository.

## Run locally

```bash
bundle install
bundle exec jekyll serve
```

Then open `http://localhost:4000`.
